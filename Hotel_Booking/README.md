HOTEL BOOKING BACKEND

Overview of program
The program works by opening into a menu, working like a frontend with persistent visual state. use of functions allow a lot of the work to be taken up by them instead of in the main function, where the variables are assigned and choice of work.

File reading
  Files are read at the start of the program, allowing for data to be read in. This also means data can be manipulated in order to debug and test. 
File writing
  Files are written at the end of the program, allowing data to be updated and kept in a persistent state anytime the program is opened up. Errors are also read when writing to a file that it cannot access.
